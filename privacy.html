1Password Ignore List

Chrome Extension · v1.0.0

Privacy Policy
Short version: This extension collects no data. It runs entirely in your local browser, makes no network requests, and never transmits anything anywhere. No accounts, no tracking, no analytics.

Effective Date

This policy is effective as of 2026-08-28 and applies to all versions of the extension.

What This Extension Does

1Password Ignore List lets you mark specific domains (and their subdomains) as "ignored" by 1Password. On a matching domain, it injects the data-1p-ignore and data-op-ignore attributes on the page's <body> element — attributes that 1Password's own extension respects to skip its save/fill prompts on that page. This is useful for local development or staging domains where those prompts get in the way. All processing happens locally in your browser tab — nothing leaves your machine.

Permissions & Why They Are Needed

PermissionWhy it is needed
storage Persists your list of ignored domains (hostnames only) via chrome.storage.sync, so it's available across your own signed-in Chrome browsers. No domain data is sent anywhere else.
activeTab Used only when you click the extension icon, to read the hostname of the current tab so the popup can show whether that domain is already ignored and let you toggle it.
host_permissions (<all_urls>) Because you can add any domain to your personal ignore list (local dev domains, staging environments, or any site you choose), the content script needs to be able to run on any page. It runs at document_start, checks the current hostname against your configured list, and — only on a match — sets the data-1p-ignore/data-op-ignore attributes on <body>. It does not read, modify, or transmit any other page content.

Remote Code

This extension does not execute any remote code. All JavaScript (content.js, popup.js, options.js) ships inside the extension package and is reviewed as part of the Chrome Web Store submission. No external scripts are loaded and eval() is not used.

Children's Privacy

This extension is a developer tool intended for software developers. It does not contain content directed at children and does not knowingly collect any information from minors.
